# 要件定義書

EC サイト（学習用）

## 目的

- EC サイトの基本的な購買フローをオンラインで実現する
- 管理者が商品を登録し、顧客がブラウザから商品閲覧・カート追加・注文を行えることを目指す

---

## ユーザー（アクター）

| アクター | 説明 |
|---|---|
| 管理者 | 商品を登録・管理する。専用の管理画面からログインする |
| 顧客 | 商品を閲覧・購入する。外部認証基盤でログインする |

---

## ユーザーストーリー

### 管理者

- [ ] 管理者として、商品（名前・価格・在庫数）を登録したい

### 顧客

- [x] 顧客として、会員登録・ログインしたい
- [ ] 顧客として、商品一覧を確認したい
- [ ] 顧客として、商品をカートに追加したい
- [ ] 顧客として、注文を確定したい

---

## ビジネスルール

- 在庫がない商品はカートに追加できない
- 在庫がない商品は注文できない

---

## スコープ

### フェーズ 1（初期実装）

- 商品管理（管理者操作）
- 商品一覧・カート・注文（顧客操作）
- 会員登録・ログイン

### フェーズ 2（拡張）

- 注文キャンセル
- 注文履歴確認
- 商品の更新・削除

### スコープ外

- 決済（モックで代替）
- 会員プロフィール管理
- ゲストカート
