## 注文処理ワークフロー

| 項目 | 内容 |
|---|---|
| 起動 | 注文が受け付けられたとき（UC-6） |
| 関与するもの | 注文・在庫・決済・カート |
| 完了 | 注文が確定する、または取り消される |

注文の状態は 受付 → 確定（成功）／取消（失敗）と遷移する。
在庫の引き当てだけは「売り越さない」を即時に守る（単一集約の強整合）。注文・決済・カートとの整合は結果整合でつなぎ、失敗は補償で戻す（→ `.claude/rules/consistency.md`）。

**正常フロー**

1. 在庫を引き当てる（同じ商品を売り越さない）
2. 決済する（モック）
3. 注文を確定し、カートを空にする

**補償フロー**（途中で失敗したら、行った処理を取り消して戻す）

- 在庫を引き当てられない（在庫不足）ときは、注文を取り消す
- 決済が失敗したときは、引き当てた在庫を戻して、注文を取り消す
